bluesky-mcp

Give any MCP agent the ability to post, read, and browse Bluesky. Account tools act as you; couchsky tools read anything public with no login — the read-only Couch Sky way.

GitHub ↗ Install Agent guide

Account tools auth

Post, reply, like, repost, follow, and read your own timeline & notifications — as your logged-in account. Needs a Bluesky app password.

couchsky tools public · read-only

Read any profile, feed, thread, or search through the public AppView. No login, no session, can never write. Reach for these first when you just need to look.

Install

git clone https://github.com/8b-is/bluesky-mcp.git
cd bluesky-mcp
npm install
npm run build

Then point your MCP client at dist/index.js:

{
  "mcpServers": {
    "bluesky": {
      "command": "node",
      "args": ["/absolute/path/to/bluesky-mcp/dist/index.js"]
    }
  }
}

Add an app password to .env for the account tools (see .env.example). The couchsky_* read tools need no credentials.
